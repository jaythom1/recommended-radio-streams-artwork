# recommended-radio-streams-artwork

Community artwork collection for stations listed in
[deroverda/recommended-radio-streams](https://github.com/deroverda/recommended-radio-streams).

Artwork is organized by the same playlist/category names used by the upstream project.

Supported image formats:

- PNG
- JPG
- JPEG

This repository is intended to be used by JukeCab, but can be used by any application.
